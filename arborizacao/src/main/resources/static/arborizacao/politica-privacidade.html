3. Dados Pessoais Coletados

O sistema coleta e trata os seguintes dados pessoais:

3.1 Dados de Funcionários (conta de acesso)

  • Nome completo – para identificação do usuário no sistema
  • E-mail – utilizado como identificador de login
  • Senha – armazenada com hash BCrypt (irrecuperável)
  • Perfil – função do usuário (Administrador ou Funcionário)

3.2 Dados de Doações de Árvores

  • Nome do doador – identificação de quem realiza a doação
  • CPF – documento de identificação fiscal (dados sensíveis, criptografados com AES-128-GCM)
  • RG – documento de identidade (dados sensíveis, criptografados com AES-128-GCM)
  • Descrição, quantidade, destinação – dados sobre a doação

3.3 Dados de Auditoria

  • E-mail do funcionário – registro de quem realizou cada ação
  • Data e hora – registro temporal das operações

4. Finalidade e Base Legal (Art. 7 da LGPD)

Os dados são tratados para as seguintes finalidades:

  • Execução de políticas públicas (Art. 7º, III) – Gestão do programa de arborização urbana do município
  • Exercício regular de direitos (Art. 7º, VI) – Controle de acesso ao sistema e auditoria
  • Legítimo interesse (Art. 7º, IX) – Melhoria dos serviços públicos de meio ambiente
  • Consentimento do titular (Art. 7º, I) – Para coleta de CPF e RG nas doações, com consentimento explícito

5. Compartilhamento de Dados

Os dados pessoais podem ser compartilhados apenas com:

  • Órgãos da Administração Pública Municipal, quando necessário para a execução de políticas públicas
  • Autoridades competentes, mediante obrigação legal ou judicial

Não vendemos, alugamos ou compartilhamos dados pessoais com terceiros para fins comerciais.

6. Transferência Internacional de Dados

Alguns serviços utilizados podem transferir dados para servidores fora do Brasil:

  • Google Fonts – biblioteca de fontes (o endereço IP do usuário é enviado aos servidores do Google)
  • VLibras – widget de acessibilidade em Libras (endereço IP é enviado aos servidores do governo federal)
  • OpenStreetMap – tiles do mapa (dados de localização aproximada)

Essas transferências são realizadas com base no legítimo interesse e em conformidade com o art. 33 da LGPD.

7. Retenção de Dados

  • Contas de funcionários – mantidas enquanto a conta estiver ativa
  • Doações – mantidas por tempo indeterminado para fins de gestão pública e prestação de contas
  • Registros de auditoria – mantidos por 5 anos para fins de controle social

8. Direitos dos Titulares (Art. 18 da LGPD)

Você tem direito a:

  • Confirmar a existência de tratamento de dados
  • Acessar seus dados pessoais
  • Corrigir dados incompletos ou desatualizados
  • Solicitar a anonimização, bloqueio ou exclusão de dados desnecessários
  • Solicitar a portabilidade dos dados
  • Eliminar os dados tratados com consentimento
  • Revogar o consentimento a qualquer momento

Para exercer seus direitos, entre em contato com o Encarregado de Dados pelo e-mail: amavisa@prefeituradavitoria.pe.gov.br

9. Segurança dos Dados

Adotamos medidas técnicas e administrativas para proteger seus dados:

  • Senhas armazenadas com hash BCrypt
  • CPF e RG criptografados com AES-128-GCM antes do armazenamento
  • Proteção contra ataques CSRF
  • Controle de acesso por perfis (Administrador/Funcionário)
  • Limite de sessões simultâneas por usuário
  • Registros de auditoria para rastreabilidade

10. Cookies

Utilizamos apenas cookies essenciais para o funcionamento do sistema:

  • JSESSIONID – cookie de sessão para autenticação (HttpOnly)
  • XSRF-TOKEN – cookie de proteção contra ataques CSRF

Não utilizamos cookies de rastreamento, analytics ou publicidade.

11. Alterações nesta Política

Esta Política de Privacidade pode ser atualizada a qualquer momento. Recomendamos a consulta periódica desta página.
